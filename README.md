# Ox Alpha — Telegram-бот с ИИ (с базой данных на сервере)

Бот хранит историю переписки в PostgreSQL — она не потеряется при
перезапуске или обновлении бота.

## Что понадобится (всё бесплатно, всё с телефона через браузер)

1. **GitHub** — чтобы хранить код.
2. **Neon** (neon.tech) — бесплатная PostgreSQL база, которая
   **не истекает** (в отличие от бесплатной БД самого Render, которая
   удаляется через 30 дней).
3. **Render** (render.com) — чтобы держать бота запущенным 24/7.

---

## Шаг 1. Залить код на GitHub

1. Откройте github.com в браузере телефона, войдите или
   зарегистрируйтесь.
2. Нажмите **+** → **New repository**. Назовите, например
   `ox-alpha-bot`. Сделайте его **Private** (там будут храниться
   намёки на структуру, ключи вы никогда не кладёте в код — только
   в настройки Render, см. ниже). Нажмите **Create repository**.
3. На странице репозитория нажмите **Add file → Upload files**.
4. Загрузите все 4 файла: `bot.py`, `requirements.txt`,
   `render.yaml`, `README.md`.
5. Внизу нажмите **Commit changes**.

## Шаг 2. Создать бесплатную базу данных на Neon

1. Откройте neon.tech → **Sign up** (можно через Google-аккаунт).
2. Создайте новый проект (Create a project) — регион выбирайте
   ближе к себе.
3. На странице проекта найдите **Connection string** — строку вида
   `postgresql://user:password@ep-xxxx.neon.tech/neondb?sslmode=require`.
4. Скопируйте её — это и есть `DATABASE_URL`, он понадобится в
   следующем шаге.

## Шаг 3. Развернуть бота на Render

1. Откройте render.com → **Sign up** (проще всего — через GitHub,
   тогда доступ к репозиторию Render получит сразу).
2. Нажмите **New +** → **Blueprint**.
3. Выберите ваш репозиторий `ox-alpha-bot`. Render сам найдёт файл
   `render.yaml` и предложит создать сервис `ox-alpha-bot` (тип —
   Background Worker).
4. Render попросит заполнить переменные окружения, помеченные как
   секретные:
   - `TELEGRAM_TOKEN` — токен от @BotFather
   - `AI_API_KEY` — ваш ключ с tokenra.io
   - `DATABASE_URL` — строка подключения из Neon (Шаг 2)
5. Нажмите **Apply** / **Deploy Blueprint**. Через 1–2 минуты бот
   запустится — статус сервиса станет **Live**.
6. Откройте своего бота в Telegram и напишите `/start`.

## Как проверить логи / что бот жив

В Render зайдите в сервис `ox-alpha-bot` → вкладка **Logs**. Там
видно все сообщения, ошибки и строку
`База данных подключена, бот запускается...`.

## Важно про бесплатные тарифы

- **Neon**: бесплатный план постоянный, но данные ограничены 10 ГБ —
  для истории чатов этого хватит с большим запасом.
- **Render (free worker)**: в месяц даётся ограниченное бесплатное
  время работы инстансов (в сумме по всем бесплатным сервисам
  аккаунта). Если бот вам нужен строго 24/7 без пауз — со временем
  может понадобиться платный план воркера (от ~$7/мес). Для
  личного использования обычно бесплатного лимита достаточно.

## Обновление кода в будущем

Просто загрузите изменённые файлы через **Add file → Upload files**
на GitHub (с заменой) и закоммитьте — Render автоматически
пересоберёт и перезапустит бота.

## Если у вас другой ИИ-провайдер
Замените `AI_BASE_URL`, `AI_MODEL` и `AI_API_KEY` в переменных
окружения Render — код менять не нужно, если провайдер совместим с
OpenAI API (как TokenRa).
